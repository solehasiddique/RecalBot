1️⃣ Introduction to Programming
What is Programming?

Programming is the process of writing instructions that a computer can understand and execute.

A program:

Takes input

Processes data

Produces output

Example:

Input: 5, 10
Process: Add numbers
Output: 15

3️⃣ Compiled vs Interpreted Languages
Compiled Language

Entire code converted to machine code before execution

Faster execution

Example: C, C++

Flow:

Source Code → Compiler → Executable File → Run
Interpreted Language

Code executed line by line

Slower but flexible

Example: Python, JavaScript

Flow:

Source Code → Interpreter → Output
Hybrid

Java is hybrid:

Java Code → Bytecode → JVM → Machine Code

1️⃣ Introduction to Rust
What is Rust?

Rust is a systems programming language focused on:

Memory safety

High performance

Concurrency

Zero cost abstractions

It was originally developed by Mozilla and is now maintained by the Rust Foundation.

Rust solves problems like:

Memory leaks

Segmentation faults

Data races

Without using a garbage collector.

2️⃣ Why Rust?

Traditional languages:

C / C++ → Fast but unsafe memory

Java / Python → Safe but slower due to garbage collector

Rust gives:

C level performance

Memory safety without garbage collection

That is Rust’s biggest advantage.

3️⃣ Installing Rust

rustc --version

Create new project:

cd project_name
cargo run

cargo is Rust’s package manager and build tool.

9️⃣ Control Flow
If Statement

if number > 5 {
    println!("Greater");

    println!("Smaller");
}

Note:
Condition must be boolean.

Loop
Infinite Loop

    println!("Running");
}

}

    println!("{}", i);

1..5 means range from 1 to 4.

🔟 Functions

    return a + b;
}

Short form:

fn add(a: i32, b: i32) -> i32 {
    a + b
}

Last line without semicolon returns value.

1️⃣1️⃣ Ownership (Most Important Concept)

Rust has unique memory system called Ownership.

Rules:

Each value has one owner

Only one owner at a time

When owner goes out of scope, value is dropped

Example:

let s = String::from("Hello");

If you assign:

let s1 = s;

Now:

s1 owns value

s is invalid

This prevents double free errors.

1️⃣2️⃣ Borrowing

Instead of transferring ownership:

fn main() {
    let s = String::from("Hello");
    print_string(&s);
}

fn print_string(s: &String) {
    println!("{}", s);
}

& means reference.

Rules:

One mutable reference OR

Multiple immutable references

But not both together.

1️⃣6️⃣ Pattern Matching

Rust uses match.

let number = 3;

match number {
    1 => println!("One"),
    2 => println!("Two"),
    _ => println!("Other"),
}

_ means default case.

1️⃣7️⃣ Option Type

Rust avoids null.

Instead uses:

Option<T>

Example:

let x: Option<i32> = Some(5);
let y: Option<i32> = None;

Handle safely:

match x {
    Some(val) => println!("{}", val),
    None => println!("No value"),
}
1️⃣8️⃣ Result Type (Error Handling)

Rust does not use exceptions.

Instead:

Result<T, E>

Example:

fn divide(a: i32, b: i32) -> Result<i32, String> {
    if b == 0 {
        Err(String::from("Cannot divide by zero"))
    } else {
        Ok(a / b)
    }
}

2️⃣1️⃣ Concurrency

Rust makes concurrency safe.

Example thread:

use std::thread;

fn main() {
    thread::spawn(|| {
        println!("Hello from thread");
    });
}

Rust prevents data races at compile time.
